# 项目素材

style_refs 目录中的五张示例图供风格库页面、后端本地基础流程和场景示意使用：

- zhuxianzhen.png：朱仙镇木版年画视觉参考
- bianxiu.png：汴绣视觉参考
- songhua.png：传统青绿山水绘画参考
- qinghua.png：青花瓷器装饰纹样参考
- jianzhi.png：中国民间剪纸视觉参考

这些名称用于区分创作参考类别，不表示五类内容具有相同的非遗项目身份。宋画青绿山水属于传统绘画风格，青花瓷纹样属于器物装饰视觉体系。

演示素材的具体来源和授权状态需由项目团队逐项核实并记录。本项目不预设所有素材均属于公共领域，也不据此主张第三方素材版权。

构建提交包时只复制本目录的项目素材和说明，不应打包 backend/.env、node_modules、venv 或缓存。
