# 华境天工界面截图

项目全称为「华境天工——AI驱动的传统文化视觉创作与沉浸式文创应用平台」。画面从本机运行的项目界面采集，涵盖首页、创作、赏析、布展和文创转化。展馆画面对应国赛展示所用的 v5 双层纹脉展馆。

> 📖 **配套视觉资产规范**：全站 GPT Image 2 高质量视觉资产提示词库与协作规范请参阅 [docs/design/GPT_IMAGE2_UI_ASSET_PROMPTS.md](../../design/GPT_IMAGE2_UI_ASSET_PROMPTS.md)。

## 采集说明

- 页面画面由 Playwright 从本机运行的 UI 截取，桌面、移动端和三维展馆采用各自的视口尺寸。
- 工作台和作品展厅使用仓库内公开案例。文化说明卡由当前界面的导出功能生成。
