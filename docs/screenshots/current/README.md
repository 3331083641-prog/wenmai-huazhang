# 华境天工界面截图

项目全称为「华境天工——AI驱动的传统文化视觉创作与沉浸式文创应用平台」。本组画面于 2026 年 11 月 25 日从本机运行的项目界面采集，涵盖首页、创作、赏析、布展和文创转化。

## 采集说明

- 页面画面由 Playwright 从本机运行的 UI 截取，桌面、移动端和三维展馆采用各自的视口尺寸。
- 工作台和作品展厅使用仓库内公开案例。文化说明卡由当前界面的导出功能生成。
