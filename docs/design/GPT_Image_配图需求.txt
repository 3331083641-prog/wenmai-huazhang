交互图层拆分说明（若后续支持 2.5D 或视差悬停）：
────────────────────────────────────────────────────────
若上述任一概念图用于前端带视差悬停的多层组件，请采用如下导出规范：
- Layer 0 (背景层 `bg.webp`)：纯背景环境、桌面纹理与漫射阴影；
- Layer 1 (主体层 `item.webp`)：透明背景 PNG/WebP，包含杯垫、手机或礼盒主体，附带真实柔和的环境闭塞阴影；
- Layer 2 (光晕/装饰层 `glow.webp`)：独立的窗格投影或高光图层，可在 CSS 鼠标悬停时做微弱位移与透明度变化。
