当前运行资源是 `frontend/public/models/WenWen_v003_gallery.glb`，源工程是 `assets/mascot/blender/WenWen_v003_gallery.blend`。从独立审阅版本派生，没有覆盖审阅源文件。展馆按包围盒缩放到 1 米身高、脚底对齐角色原点，并旋转 π 弧度，将 GLB 的 +Z 正面与控制器 -Z 前进方向对齐。模型材质使用原 PBR 贴图，开启受硬件限制的最高 8 倍各向异性过滤。

展馆运行版保留全部几何，将原来超过 1024 像素的 9 张图片缩至 1024 像素，保留颜色、法线、粗糙度和金属度材质连接，减少纹理显存占用。GLB 由最初绑定版本的 36,034,660 字节降至 27,024,020 字节。独立审阅版高分辨率贴图未被改动。

保留已有碰撞、楼梯、视角切换和展品文化卡逻辑。模型可用性探测使用 4 字节 Range 请求，避免支持 Range 的服务器重复传输整个模型。
