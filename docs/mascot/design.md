# 纹脉展馆吉祥物「纹纹」· 概念设计

> 前置研究见 [research.md](./research.md)：官网页面是获奖名单公告，没有作品图；5 件获奖作品里只有「狮小炸」有公开文字描述，其余 4 件未获取到造型信息。因此本方案只借鉴**方法**（先定情绪、把工艺翻成可触材质、按跨媒介自检），不复制任何角色轮廓、五官、配饰或配色组合。

## 0. 差异化从哪来

研究里有一条量化事实：官方名单「IP 形象类」中**瓦猫 10 件、醒狮 3 件、布虎系 ≥2 件**——「瑞兽萌化 + 叠字名」已经非常拥挤。所以「纹纹」刻意避开这三条母题：

- 不复刻门神/醒狮的兽头+绒球组合；
- 不做瓦猫的蹲守陶兽；
- 不当「穿汉服的 Q 版猫」。

它来自项目自己的作品《瑞猫迎春》——一只年画里的猫，被做成展馆的「非遗守护灵猫」。原创记忆点只押三件：**卷云尾、线刻耳缘、额心祥云印**。去掉所有配饰，靠剪影（大圆头 + 螺旋尾）也能认出。

## 1. 三套方案

### 方案 A · 卷云灵猫（选定）

- **一句话**：从年画里走出来的小猫，尾巴卷成一朵云。
- **造型**：头身比 1 : 1.35，头大、身短、四肢短而圆；脸颊有肉感但不臃肿；耳朵大而尖，外缘做 2–3 个浅浅的**木刻刀口**；眼睛占脸宽约 1/3，青绿虹膜 + 白高光；额心一枚**卷云勾线祥云印**（金边、青绿填充，占额头约 1/4）。
- **剪影记忆点**：尾巴末端卷成传统**卷云纹螺旋**，比头略高，永远露在轮廓外。
- **配色**：米白 `#F3E7CF` 主体，暖灰 `#D8C6A6` 暗部，朱红 `#B5322C`（耳内 + 尾尖卷云），青绿 `#2F6F66`（祥云填充 + 项圈夹色），金 `#C9A24B`（描边 + 挂饰链），深褐 `#3A2A1C`（眼圈/耳缘结构线）。
- **文化元素（只用两至三个主要特征）**：木版年画的线刻（耳缘）＋ 传统祥云（额印与尾形）；配饰才用青花瓷牌与汴绣项圈，且可替换。
- **表情**：好奇（耳朵前倾、瞳孔放大）、开心（眼睛弯成月牙、尾巴竖起）、困倦（半垂眼睑）、惊讶（耳朵后压、身体微后仰）。
- **性格**：温柔、好奇、有点小得意；不吵闹，像一个会陪你逛展的小孩。
- **三维可实现性**：全部为可蒙皮的实体几何（圆头、耳、五段尾、短肢），无飘带、无毛发片、无镂空薄片，适合 ≤18k 面与 8 个纯色材质。

### 方案 B · 剪纸影猫

- **一句话**：一张红纸剪出来的猫，走动时像被风轻轻掀起。
- **造型**：极简剪影，负形镂空（云纹、花瓣）直接作为身体的一部分；正面非常出彩，但**侧面几乎没有体积**。
- **配色**：正红 `#C0261F` + 米白纸 `#FBF7EE` + 深红阴影。
- **文化来源**：中国剪纸（项目五风格之一），负形与刀路。
- **问题**：三维化只能做成「厚纸板」，转身与行走容易露馅；动画上难做次级运动（纸片不能自然弯），与现有展馆的实体木构气质偏冲突。
- **结论**：保留为设计记录，适合做平面海报/贴纸延展，不做主吉祥物。

### 方案 C · 瓦猫守灵

- **一句话**：屋脊上的瓦猫活过来，灰陶身上有瓦当纹。
- **造型**：蹲坐姿态、身体方、头大眼圆、口中含脊兽牙；表面做陶土粗颗粒与瓦片叠压。
- **配色**：陶灰 `#8D8577` + 瓦青 `#4E6B6A` + 少量朱红点。
- **文化来源**：云南瓦猫镇宅习俗。
- **问题**：一是研究显示瓦猫赛道已有 10 件同类作品， originality 风险最高；二是蹲坐体态不适合走跑跳的玩家操控；三是灰陶色调在展馆里辨识度低。
- **结论**：保留记录，不做主吉祥物。

## 2. 评分（1–5，越高越好）

| 维度 | A 卷云灵猫 | B 剪纸影猫 | C 瓦猫守灵 |
|---|---|---|---|
| 原创性（去掉配饰仍可辨识） | 5 | 4 | 2 |
| 文化辨识度（能说出对应非遗） | 4 | 4 | 4 |
| 可爱度（治愈系潮玩） | 5 | 3 | 3 |
| 三维可实现性 | 5 | 2 | 4 |
| 动画适应性（走跑跳、次级运动） | 5 | 2 | 3 |
| 与现有展馆风格统一 | 4 | 3 | 4 |
| **合计** | **28** | **18** | **20** |

**选定 A**。它的风险最低、动画最自由，且「卷云尾」是一个能跨媒介复用的图形资产（logo、贴纸、盲盒都能用）。

## 3. 选定方案的落地规格

| 项 | 值 |
|---|---|
| 身高基准 | 1.00 m（网页里按展馆门高与台阶再缩放） |
| 头身比 | 1 : 1.35 |
| 面数预算 | ≤ 18k 三角面，材质 ≤ 8，无贴图 |
| 原点/朝向 | 两脚之间地面，正面 -Z（与展馆资产契约一致） |
| 骨骼 | root / hips / spine / chest / neck / head / ear.L·R / 眼睑 / tail.01–05 / 四肢 ×2 段 + 脚掌 |
| 动作 | Idle / Spawn / Walk / Run / Turn / Happy / Curious / Interact（8 段，见建模任务） |
| 描边 | 不用贴图描边；在模型上保留深色耳缘、眼圈作为结构线，网页端可再叠一层三渲二描边 |

## 4. 三视图与表情

三视图、3/4 视角与表情由 Blender blockout/成品直接渲染交付，放在 `docs/mascot/previews/`：

- `front.png` / `side.png` / `back.png` / `three-quarter.png`：验证正、侧、背、俯视都成立，不是只在一个镜头好看。
- `anim-*.png`：动作极值帧，检查耳朵、尾巴的次级运动。

诚实说明：本轮的概念呈现是**三维 blockout 渲染**，不是插画设定稿；好处是所见即所得、比例可直接进建模，代价是没有手绘设定稿那种表现力。

## 5. 与获奖作品的关系（合规声明）

- 只借鉴方法：情绪先行、工艺→可触材质、跨媒介自检。
- 未复制任何获奖作品的轮廓、五官、配饰、配色组合；未使用任何他人作品图作为生成输入。
- 研究只找到 1 件作品的文字描述（狮小炸），本方案与它在题材（醒狮 vs 猫）、轮廓（兽头绒球 vs 卷云尾）、配色（多巴胺撞色 vs 米白/朱红/青绿/金）上均可区分。
