## 自动流水线的实际修复

1. 去除按风格复用的自动章节与语义模板，新作的热点、局部观察和章节只由本地 Qwen3-VL 读取本图后生成。
2. 增加逐局部读取，再以实际观察生成叙事；校验坐标、标题重复和章节引用。自动结果仍不等于人工事实核验。
3. 修复构建时旧快照盖过后台状态的问题；展厅自动刷新，三个入口无需重启前端。
4. 新资产改由后端动态提供，解决 Vite 启动时未收录新文件的问题；重建版本避免继续取旧纹理。
5. 修复普通图片缓存与 WebGL 跨源纹理复用的问题；失败及超时不再因旧文件存在而显示就绪；同件作品活动任务避免并发写入。
6. 安装并校验固定版本 Depth Anything V2 Small，本地推理成功；后台只读本地权重，不隐式下载。
7. 按视口和原图比例计算入场取景；修正图片顶部原点与纹理底部原点之间的点击转换。
8. 白底主体采用完整轮廓分层，山水保留平滑深度网格，减少细长形体的拉扯；相机、纹理、热点与本图绑定。
9. 删除作品时同步移出互动资产、清理任务与前端缓存/作品池，保留本机私有回收副本；不删除五件精选。

- 生成与互动构建是先保存、后异步完成，不承诺全部在出图同一瞬间结束；真实服务不可用时明确反馈。
- 自动定位、视觉识别与文化联想仍可能偏差，不宣称“完美”、历史事实核验或恢复真实尺度。
- 完整主体分层提供轮廓保持与视差/微动，不等于骨骼动画或物体背面重建；五种测试不能覆盖任意输入。
- 文创与外部场景图用于设计预览/构想，未验证实体生产、物理大屏联动或商业部署。
- 首次安装完整深度环境需要下载依赖和权重；本轮在本机既有 Python 环境内完成安装校验和推理，未声称在全新 Windows 系统重新装机验证。
- Vite 仍提示约 2 MB 的主 JavaScript 分块偏大；本次未为此改造技术栈或大规模拆分界面。
