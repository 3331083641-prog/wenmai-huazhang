## 二、统一三维契约（母模型）

十图并非严格同一相机参数下的同一模型，因此先固定一套**唯一坐标系**，所有视角都必须能由它渲染出来。

- 坐标：Z 向上；X 向右（正面朝 −Y）；原点在底座几何中心。
- 单位：米；底座平面 **16.0 × 16.0 m**（基准 1.0 → 16 m）。
- 建筑主体（墙体外皮）：**10.4 × 9.0 m**（0.65 × 0.5625 基准），建筑中心 y = +0.60（略后置）。
- 前场街道进深 ≈ 2.6 m，左右各留 2.8 m，后侧 0.5 m —— 保证 45° 默认视角能读出“街角”。
- 竖向分层（估算）：

| 层 | z 范围 | 高度 | 说明 |
|---|---|---|---|
| 底板托架 | −0.30 – 0.00 | 0.30 | R04 可见的底部木托架 |
| 须弥座 | 0.00 – 0.90 | 0.90 | 深灰石，四面回纹带 + 中央团花 |
| 青石平台 | 0.90 – 1.50 | 0.60 | 浅灰石板，边缘压顶石 |
| 一层 | 1.50 – 4.10 | 2.60 | 入口、格扇、展柜 |
| 腰檐层 | ≈ 4.00 | — | 环绕一周的小披檐，形成重檐 |
| 二层 | 4.10 – 6.60 | 2.50 | 开放展廊 + 室内挑空 |
| 主屋顶 | 6.60 – 9.60 | 3.00 | 庑殿式（四坡），正脊 + 垂脊 + 翘角 |
| 脊饰顶 | 9.60 – 10.00 | 0.40 | 鸱吻/宝顶 |

- 一、二层高度比 ≈ **1.04 : 1**（近等高，二层略矮）。
- 主屋顶檐口宽度 ≈ **1.22 × 主体宽度**（出檐深，檐下可见椽与斗拱层）。
- 总高/建筑宽 ≈ 9.6 / 10.4 ≈ 0.92；总高/底座边 ≈ 0.63。

**一致性判定（必须同时通过）**
1. 正脊只在 X 方向一条，两端各一只鸱吻；顶视中脊线居中、不放射。
2. 四条垂脊从正脊两端斜下到四角，四角起翘。
3. 屋面瓦垄**沿坡面平行排布**，不是从中心放射。
4. 腰檐绕建筑一周，在正面被匾额与入口打断。
5. 楼梯位于一层后墙偏右，直跑上二层，梯口落在二层回廊。
6. 二层中央挑空（约 5.4 × 4.6 m 洞口），四周回廊宽 ≈ 2.0 m。
7. 15 个画框分布在：一层左右展墙、二层四周回廊墙、楼梯间对面墙。

## 三、逐图观察要点

### R01 室内仰视
- 中央**方形藻井**：外方框 → 内凹两级 → 中央圆形团花（米金底 + 蓝绿卷草 + 莲瓣）。
- 椽条从藻井向四周**放射状**延伸到檐口（这里放射是对的，因为顶棚是攒尖式的），与屋面瓦垄的放射**无关**。
- 梁架三级：大梁（最粗，深棕）→ 次梁 → 椽；梁端有金色斗拱块。
- 悬挂：正中央六角宫灯（米色纱面 + 木框 + 朱红穗），四角各挂 1 只朱红圆灯笼。
- 二层回廊栏杆为**短柱 + 棂格**，栏杆下有金色雕花挂落。

### R02 / R07 主立面
- 三开间：中间门洞（宽 ≈ 2.5 m，高 ≈ 2.4 m，敞开可见内部），两侧格扇（每侧 1 大扇 + 上亮子）。
- 匾额悬于二层栏杆下沿，黑底金框、金字，宽 ≈ 2.6 m、高 ≈ 0.64 m，位置略偏门洞中心上方。
- 二层：**开放外廊**（不是白墙方格窗），木质栏杆 + 挂落，栏杆后为格扇门/窗，室内可见瓷瓶与挂画。
- 檐下：椽头 + 斗拱层 + 檐板三层分明，暖木色。
- 灯笼：一层檐下 2 只、二层檐下 2 只、柱间 2 只；右侧竖幡「非遗」（米色底、墨字、红印、红穗）。
- 墙：暖白抹灰 + 深棕木框，勒脚为浅灰条石。

### R03 / R08 侧立面
- 右前（+X 侧）有**单层附属披檐**：小歇山/腰檐 + 米色条纹遮阳篷，篷下为木质格扇展示窗。
- 左侧（−X 侧）：腰檐连续，二层有外廊栏杆，一层为格扇窗；竹丛、花坛、石灯贴墙布置。
- 山墙转角处有**转角柱 + 雀替**，木构包角。
- 后立面（R08 可见部分）：白墙 + 高窗 + 腰檐，比正面简洁，但仍有木构层次，不能是纯白盒。

### R04 悬浮展台
- 底座 = 两层：上层浅青灰石板平台（边缘压顶石，略出挑），下层深灰须弥座（带束腰）。
- 须弥座四面：上下各一道**回纹（雷纹）雕带**，中央**圆形团花**（八瓣莲 + 卷草），四角为方块石。
- 底部有**木托架**（4–6 根短梁）把整个展台“抬起”，说明这是一个可搬动的收藏模型。
- 须弥座下沿有细微倒角与阴影层，石面有轻微颗粒感、无强反射。

### R05 鸟瞰
- 屋面：前后两大坡 + 左右两坡，构成庑殿；瓦垄沿坡面平行，约 **26–30 垄/坡**，垄宽 ≈ 0.30 m。
- 正脊：深灰瓦叠砌线脚，两端鸱吻上翘带金饰。
- 垂脊：四条，脊端小兽/翘角。
- 檐口：瓦当一排（圆形带纹），檐下有椽头阵列（每 0.3 m 一根）。
- 院落：正面与左侧为青石板铺装（大方砖 + 缝隙），墙根有花坛、竹、树池。
- 建筑占地明显小于底座，四周留白充足。

### R06 细节板
- 檐角：瓦当圆形 + 滴水，转角处起翘明显，椽头方形。
- 转角木构：柱头有金色雕花箍，雀替卷草纹。
- 竖幡：木杆 + 横挑 + 幡面（米色）+ 红穗 + 印章。
- 灯：朱红圆灯笼（竹骨 8 条）、方形石灯（暖光窗）、六角宫灯。
- 楼梯：深棕木踏步 + 实木栏板 + 方形望柱（柱头有金饰）。
- 展柜：深木底座 + 玻璃罩 + 内部暖光 + 展签。
- 须弥座团花：八瓣莲，外圈卷草，石质浮雕。

### R09 二层室内
- 中央**挑空**，四周回廊（宽 ≈ 2.0 m），栏杆高 ≈ 1.0 m，望柱方形。
- 挂画：成组布置（三联/五联），画心米黄绢底，木框细边。
- 窗：格心窗（冰裂/步步锦），外侧可见天空与树。
- 地面：深色木地板（人字/直铺），走廊有红毯。
- 天花：外露梁架 + 局部彩画。

### R10 一层室内
- 中央：**长条展台**（木箱体 + 玻璃罩 + 内部灯光 + 展品），台面高 ≈ 0.9 m。
- 后墙正中：**楼梯**（直跑，宽 ≈ 1.2 m），梯下为储物/展柜；楼梯两侧为展墙。
- 两侧沿墙：一排**玻璃展柜**（内有瓷器）+ 上方挂画（竖幅为主）。
- 地面：浅青石方砖 + 正中央**红毯**（带回纹边框）。
- 顶部：外露木梁 + 中央六角宫灯 + 侧向射灯。
- 光：整体暖白，射灯打画，窗口日光偏冷形成对比。

| 构件 | 实现方式 | 关键参数 |
|---|---|---|

| 主体墙柱 | 柱阵列 + 墙板 + 勒脚条石 | 柱径 0.28，开间 3.4/2.6/3.4 |

| 楼梯 | 踏步 + 斜梁 + 栏板 + 望柱 | 宽 1.2，21 级 |
| 匾额 | 文本对象（系统字体）+ 金框 | 2.6×0.64 |
| 灯笼 | 竹骨 + 纱面（自发光）+ 上下盖 + 穗 | 直径 0.45 |
| 展柜/展台 | 木箱体 + 玻璃罩（低粗糙度透明） + 内灯 | 高 0.9/2.1 |
| 挂画 | 15 个独立命名对象 + 可替换面片 | 独立 mesh，不合并 |
| 植物 | 树干 + 叶簇（低面数簇群，非球） | 树高 3.2，竹 4.0 |
| 地面铺装 | 方砖阵列 + 缝隙 | 砖 0.9×0.9 |

### 与 Three.js 的边界
- 画框、灯笼、可替换展品保持**独立命名对象**，不并入合并网格。
- GLB 导出保留 extras（对象名 + `frame_id`），Three.js 通过名字定位 15 个画框。
- 旧管线（`build_all.py` / `exports/gallery_layout.json`）保持可用，V4 先输出到 `exports/wenmai_gallery_v4.glb`，验收后再切换。

## 六、S1 验收口径（白模阶段）

只允许评价：体块比例、屋顶形式、二层展廊开口、楼梯连通、底座与街角占比。
**严禁**用瓦片、灯笼、植物数量掩盖结构问题。

判定项：
1. 顶视：正脊为一条直线，四坡划分清楚，瓦垄平行于坡向。
2. 45° 鸟瞰：能同时看到主屋顶、腰檐、二层栏杆、一层门洞、街角铺装、完整底座。
3. 侧视：+X 有附属披檐，−X 有连续腰檐，后立面非纯白盒。
4. 剖面：楼梯从一层贯通到二层回廊，不穿墙、不悬空。
5. 室内：二层挑空可见一层天花板，栏杆连续。

> 后续阶段（S2 细部 / S3 室内策展 / S4 材质灯光 / S5 Three.js / S6 三轮对照）见 `docs/heritage_gallery/v4/`。
