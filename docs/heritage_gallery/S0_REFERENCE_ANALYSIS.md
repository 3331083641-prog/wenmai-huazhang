## 1. 量测方法

每张图统一换算到 1448×1086（参考图原始尺寸），再做三件事：

| 指标 | 定义 | 为什么需要 |
| --- | --- | --- |
| `coverage_pct` | 与画面四边连通的背景被剔除后，剩下前景像素占比 | 判断建筑在画幅里占多大，直接决定相机距离 |
| `sky_frac` | 顶部区域里蓝色系（B 显著大于 R）像素占比 | 判断是否是仰视/平视，有没有天空 |
| `bg_frac` | 背景像素占比 | 判断是白底展板还是实景照片 |
| `hedges_y` / `vedges_x` | 行/列方向的梯度能量峰位置（归一化） | 找檐口、腰檐、台基这些水平分层 |
| `palette` | 量化到 32 色后的主色及占比 | 定调色板，三渲二的分档色就从这里来 |

三渲二需要的是**几档平涂色**，所以主色统计比单像素采样有用得多：它能直接告诉我
「屋面是 #484848 一类的冷灰，木构是 #482818 一类的暖深褐」。

### 三条由此得出的硬结论

1. **六张实景外观 + 一张实景室内 + 三张白底细节展板。** 也就是说，
   「07 室内一层 / 08 室内二层 / 09 室内仰视屋顶」这三张**并没有全部拿到实景**，
   只有一张（G）是可用的室内照片；另外三张白底展板（H/I/J）是细节板——
   分别偏米白（木构/窗棂）、偏天蓝（青瓦/彩画）、偏朱红（灯笼/柱身）。
2. **没有任何一张是正俯视。** 六张外观图的天空占比都在 10 %–23 %，
   正俯视不会有天空。所以任务书里的「05 顶部俯视」在原始素材里对应不到一张专用参考，
   **屋面形制只能从其余五张的可见斜面反推**。这一条直接决定了屋顶的建模方式（见 §4）。
3. **色调是暖深褐 + 冷灰 + 米白三段。** 主色几乎只落在
   `#482818`/`#583828`/`#683818`（木构）、`#484848`/`#584848`/`#887878`（屋面瓦作）、
   `#f8e8c8`/`#f8f8d8`（墙面与白灰）三族，以及极窄的一条天蓝。
   三渲二的 `TOON_PALETTE` 就是从这三族取的，不是凭感觉配色。

## 3. 十张图之间的矛盾，以及我的取舍

一次建模不可能同时满足十张图，必须定优先级。任务书给的优先级是
**整体体量 → 正面入口与两层结构 → 顶视屋顶 → 左右背面 → 内部楼层与楼梯 → 细节 → 非关键装饰**，
我按这个顺序逐条裁决，并把裁决结果写进模型参数：

| 冲突 | 图与图的说法 | 裁决 | 依据 |
| --- | --- | --- | --- |
| 一层出檐层数 | A/C 看到一层挑檐 + 腰檐两条水平带，E/F 只看到一条 | 做**两层出檐**（一层挑檐 + 腰檐），腰檐比挑檐薄 | 水平梯度峰在 A 中是成对出现的，单看一张会漏 |
| 台基高度 | D（近景）台基占画高约 1/4，A 只占 1/7 | 取 `0.75 m` 高、`12×12 m` 方形台基 | 近景图透视压缩更小，更可信；同时要满足"能走进去"的尺度 |
| 屋顶坡度 | 各图在 26°–34° 之间浮动 | 取 30°，凹曲指数 1.55 | 取中值；凹曲是为了对上山墙那条内凹的檐口线 |
| 翼角起翘 | 只在 D 看得清 | 起翘量 0.62 m | 只有近景可信，其它图角度看不到 |
| 面阔开间数 | 正面 5 间还是 7 间不一致 | 5 间 | 正面图为 C，杆件间距在 C 里数得最清 |
| 室内层高 | 只有 G 一张室内 | 一层 3.35 m，二层 3.05 m | G 的柱高与画框比例反推，且要留出两层可用展墙 |

**只有一张室内照片**这件事必须说清楚：室内楼梯、二层楼板、梁架的具体做法，
是从 G 的可见部分 + 常规重檐楼阁的构造常识推的，不是十张图逐张对上来的。
这一点在 `FINAL_ACCEPTANCE.md` 的"尚未完成的问题"里也再写了一次。

## 4. 结构定稿（建模前就锁死的参数）

单位米，+Z 向上，原点在台基中心，台基顶面 `z=0`。

| 项 | 取值 |
| --- | --- |
| 台基 | 12.0 × 12.0 × 0.75，四周设踏步 |
| 建筑平面 | 8.0 × 6.6（面阔 × 进深） |
| 一层层高 / 二层层高 | 3.35 / 3.05 |
| 正脊高度 | +2.25（相对二层檐口） |
| 檐口出挑 | 上檐 1.55，腰檐 1.28 |
| 屋面坡度 / 凹曲指数 | 30° / 1.55 |
| 翼角起翘 | 0.62 |
| 总包络（导出实测） | `[-6.17, -1.05, -6.17] → [6.17, 9.65, 6.17]` |

屋顶用**放样环**做的（`roof_rings`），不是四块斜板拼的：每一圈是同一套
`(x, y, z)` 采样，z 由凹曲指数和翼角起翘共同决定，这样六个面的檐口线才是连续的。
正俯视没有参考图，因此屋顶的**平面轮廓**只能靠这套放样自洽，不能声称与 05 图逐像素对齐。

## 5. 展陈相关的量测（不复制画作）

任务书明确要求**不复制参考图里的画作**，只复刻框、装裱、悬挂方式、位置、展墙、展签、灯光。
所以参考图里的画只被用来读三个数：**框的长宽比、框与墙的比例、框心高度**。

- 画框可视区比例：`FRAME_IMAGE_RATIO = 0.74`（框心占框外廓的 0.74，其余是卡纸与边框）
- 画框中心离地：一层 1.62、二层 4.87（与 `gallery_layout.json` 里的 `frames[].center` 一致）
- 展墙厚度：`WALL_THICKNESS = 0.16`
- 画框贴墙偏移：0.06（正好落在展板表面，不嵌进墙也不悬空）

画框数量：**一层 8 个，二层 7 个**，共 15 个。每层都 ≥ 6，满足"每层至少 6 个"的要求。

## 6. 这一步没能做到的事（如实记录）

- **视觉模型不可用。** 本轮所有"像不像"的判断都不是让模型看图得出的，
  而是上面这套统计量比对出的。期间尝试调用视觉能力时返回
  `429 daily_rate_limit_exceeded`（当日免费额度 20 次已用完），没有替代方案可用。
  因此本文不含任何"像素级一致"的结论，只有可复算的数值与差距。
- **参考图编号与上传顺序不一致**，我没有强行把某张图认定成某号。
  本文用内容哈希前 8 位标识图，避免"第几张"这种容易错的引用。
- **俯视无参考**，屋面平面轮廓的自洽性靠放样保证，不声称与某张图对齐。

下一步（S1 主体建模）的输入就是 §4 这张参数表，不再改动。
